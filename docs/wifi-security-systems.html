Buyer's guide

Do I need professional monitoring?

No. Most kits send phone alerts and sound a siren for free. Paid monitoring adds a call center that dispatches police or fire, and some insurers offer a discount for it.

What's in a typical kit?

A base station with a siren, a keypad, door and window sensors, and a motion sensor. Larger kits add more sensors and range extenders.

Will it work if the internet goes down?

The base station's siren still works. Some systems include a cellular backup that keeps alerts going, usually on a paid plan.
