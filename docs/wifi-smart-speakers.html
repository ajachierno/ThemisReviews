Buyer's guide

Alexa, Google, or Siri?

Pick the assistant that matches your phone and smart home. Echo speakers run Alexa, Nest speakers run Google Assistant, and Sonos speakers can use Alexa or Sonos Voice Control.

Can a smart speaker be my hub?

Some can. Several Echo models have a Zigbee hub or Thread border router built in, and Nest speakers and displays can be Matter controllers. Check the listing if you want it to run your devices too.

How much should I spend for sound?

Small speakers like the Echo Dot are fine for voice and casual music. If music matters, a larger speaker like a Sonos Era is a big step up.
