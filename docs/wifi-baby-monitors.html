Buyer's guide

Wi-Fi monitor or local display?

Wi-Fi monitors let you watch from your phone anywhere. Monitors with a parent display work without Wi-Fi in the house. Some do both.

Do I need a subscription?

Some smart monitors put sleep tracking and cloud video behind a plan. Live view is usually free. Check before you buy.

Is a security camera good enough?

For basic watching, yes: a cheap pan-and-tilt indoor camera works as a baby monitor. Dedicated monitors add a parent display, lullabies, room temperature, and cry alerts.
