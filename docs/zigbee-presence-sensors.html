Buyer's guide

Presence sensor or motion sensor?

A motion sensor (PIR) sees movement, so lights turn off if you sit still. An mmWave presence sensor detects breathing-level motion, so it knows you're still in the room while you read or work.

Do presence sensors need power?

Most mmWave sensors need USB or wall power because the radar runs constantly. A few newer battery models combine PIR and mmWave to save power.

Can it tell where I am in the room?

Some models, like the Aqara FP2, support zones, so a desk, couch, and bed can trigger different automations.
